## 核心观点

以下为访谈观点的归纳，不是对所有发言的事实背书。

### 1. 让 AI 持续参与具体任务

访谈中，孙宇晨介绍了将饮食照片、训练记录和睡眠数据交给 Claude Code 整理的做法，强调记录、执行、反馈与调整之间的连续性。

### 2. 把个人资料沉淀成可迁移的文档

将目标、背景和进度保存在 Markdown 文件中，方便后续读取与交接。访谈以从 Claude Code 切换到 Codex 为例，讨论如何让长期记录跟随使用者积累。

### 3. 从熟悉的领域寻找 AI 的切入口

他关注数据丰富、分析需求大的方向，如天文、生物、健康管理与数据处理。可提炼的方法是结合领域知识识别具体问题，再探索 AI 能参与的环节。

### 4. 将健康纳入长期规划

访谈用「碳基服务器」比喻身体，强调运动、睡眠和日常状态对持续工作的影响。文中的具体医疗说法、训练效果与寿命预测未经本仓库核验。

### 5. 保持独立判断，也愿意修正自己

对谈同时强调行动中的自主性与 small ego：减少外界评价的干扰，保留学习新信息、承认不足和调整行为的空间。

### 6. 为职业与生活保留机动性

孙宇晨以「逐水草而居」描述自己的选择逻辑，重视在城市、行业和机会之间调整的能力，并将其与他对财富自由的理解联系起来。

### 7. 关注 AI Agent 与支付的结合

他看好稳定币、微支付和机器之间的结算。这是嘉宾作为加密行业参与者提出的商业判断，具有明确的个人立场。

### 8. 在体验中形成判断，把经历转化为创造

对谈后半段讨论人生意义、探索与创造，提出先体验、逐步形成判断，并将经历转化为作品、产品或教育等创造活动，同时给休息留出空间。
